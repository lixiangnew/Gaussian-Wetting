# M2：高斯分区与代表体积（方案 A）

独立实验，保留既有 `stage_a_internal`、`stage_b_transport` 和 C 阶段不变。
本目录实现高斯体积/容量分配，不实现新的输运、有效面或时间推进。

## 方法及边界

使用峰值为 1、无 determinant/旧体积预因子的完整高斯核：

`G_i(x) = exp(-0.5 * (x-mu_i)^T Sigma_i^-1 (x-mu_i))`

同一已知连通域内 `psi_i = G_i / sum_j G_j`；积分区域仅为物体内部。
`V_i = sum_k w_k psi_i(x_k)`，`C_i = rho * sum_k w_k psi_i(x_k) phi(x_k)`。
有效孔隙率为 `C_i/(rho*V_i)`，不能用节点中心的孔隙率代替容量积分。

这是**本项目构造**，借鉴文献的 partition-of-unity 有效体积定义；未声称
文献已证明本项目的任意各向异性高斯 Darcy 输运。

- 主求积为复合中点；独立加密的复合 4 点 Gauss–Legendre 求积提供参考。
- 所有节点参与同域计算，没有 KD-tree、核截断或近邻近似。按积分点分批，避免存储 Q×N 全矩阵。
- 物理节点位置与求积点独立；求积格不保存水质量，也不建立输运边。
- 1D 的 `measure_scale` 是横截面积（m²），2D 是厚度（m），3D 为 1。
  因而输出 volume/pore_volume 为 m³、capacity 为 kg，水密度默认 1000 kg/m³。
- 非均匀孔隙率界面通过同标签、不重叠的积分子盒明确切分，不将积分子盒当作隔水域。
- 完整高斯在有限坐标下理论上有正分母；使用移位对数权重防下溢。
  缺少域支持时报错；距离超过 3σ 记录为覆盖诊断，不因归一化成功就认为覆盖合理。
- 当前几何为已知盒体并集；复杂凹域局部裂缝、曲面裁剪不在验收范围内。
- 总量闭合不代表局部分配准确：必须独立检查每个节点体积的求积收敛。
- 首轮核宽/分辨率扫描用于总量检查和与继承格体积对照，并不表示扫描中每一组的局部积分误差均已达到统一精度。

### 6912 节点实验的精算方式

采用 24×24×12 的笛卡尔节点、轴对齐等宽可分离高斯。
在这种特殊情形，分母是三个一维核和的乘积，故三维分区也精确分解为一维分区的乘积。
体积由三个一维**高斯分区积分**相乘获得，而非继承方格体积。
先用通用全节点三维中点积分交叉核对同一求积规则，再用 24/48/96/192 分段、
每段 4 点的一维求积构造三维高精度参考。此加速不推广到一般扰动/旋转核。
实际通用非规则 3D 验证使用 64 个扰动节点；大规模非规则性能尚未验收。

## 运行

从仓库根目录运行（Python 3.9+、NumPy；绘图额外使用 Matplotlib）：

```powershell
python -B -m unittest discover -s stage_m2_partition -p 'test_*.py' -v
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
python -B stage_m2_partition/run_experiments.py
python -B stage_m2_partition/plot_results.py
```

已用环境：`D:\Anaconda\envs\pytorch\python.exe`。上述 `python` 可替换为此解释器。
重复实验默认覆盖本目录 outputs；可用 `--output <另一个目录>` 保存独立实验结果。
绘图脚本也接受相同 `--output`，结果摘要写到该输出目录的父目录。
随机种子、Python/NumPy 版本、Git HEAD 和源文件 SHA256 写入报告；
未提交的新增文件以源文件哈希为准，Git HEAD 不独立代表此次实验代码。
耗时是本机单次墙钟时间，不是公平的 FVM 性能比较；本轮没有测量峰值内存。
