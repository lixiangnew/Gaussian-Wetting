# B 阶段代码阅读路线

## 1. 与 A 阶段的区别

A 阶段告诉我们“材料在哪里、每个节点有多少体积、哪些节点相连”。B 阶段新增的是“每一时刻有多少水，以及下一小段时间水怎样移动”。物体位置和体积仍固定。

首先阅读 solver.py 的 State，再读 Transport.rates、exchange、Transport.step 和 Transport.run，最后读实验与 research.py。不要从全部第三方依赖开始。

## 2. State：只保存质量，避免重复存储矛盾状态

```python
state.pore       # [N]，每个内部节点的水质量，kg
state.surface    # [B]，每个供水表面的库存，kg
state.free       # 一个数，尚未送入表面的外部库存，kg
```

`vector()` 将三者接成 `[N+B+1]` 的一维数组，使内部交换、吸收和供水都能调用同一套保守交换函数。最后一个位置对应 free。

饱和度通过 `saturation()` 计算：S=m/capacity。`np.divide(...,where=capacity>0)` 避免零容量除零；这些节点 S 定义为 0。B 阶段不修改 A 模型中的初始 saturation。

表面等效深度为 h=surface/(ρA)。h 与内部 S 是不同状态；完全允许内部还未饱和而表面已经积水。

## 3. Material.response：从 S 得到压力和相对渗透率

返回两个 [N] 数组：pc 为正的毛细吸力大小，kr 为无量纲相对渗透率。

linear 分支是 pc=P0(1−S)、kr=1，主要用于验证：湿端 S 高，pc 小，p_w=−pc 更高，水自然流向干端。常数参数下它退化为可求解析解的扩散方程。

vg 分支令 m=1−1/n：

```text
pc = P0 (S_eval^(-1/m) − 1)^(1/n)
kr = sqrt(S) [1 − (1 − S^(1/m))^m]^2
```

S_eval=max(S,eps) 避免完全干燥时压力发散。eps 只作用于本构查询，没有向材料加水；kr 仍允许 S=0 时为 0。当前残余饱和度设为零。这是正则化的指定模型，未标定材料，也不能用 eps 调出漂亮视频后宣称物理准确。

函数内部的 `np.clip(s,0,1)` 仅防止构成公式因浮点量级越界失效，不对 state.pore 做裁剪。更新后直接 clip 水量会破坏质量守恒，测试中包含此反例。

## 4. Transport.__init__：预计算固定几何项

构造时保存容量、重力、材料参数。k 可以是标量、三个轴向值或 [N,3] 的逐节点对角值。没有接收任意 3×3 张量的接口，避免把简单两点公式误用于一般非正交情况。

每条内部边的端点为 i、j，方向为 n。方向渗透率是 Σ_d k_d n_d²。对本阶段轴向边，只会取到对应轴的 k。

两端固有渗透率使用调和平均：2ki·kj/(ki+kj)。任何一端为零，平均值为零，通量也为零。零孔隙率节点的 k 显式置零。

预计算 conductance=ρ A κ_harmonic/(μd)，单位 kg/(Pa·s)。乘以相对渗透率与压力差，得到 kg/s。

geometry.boundary_face 给出表面节点、面面积、面中心和到单元中心的半格距离。这里只提取模型最外侧的完整平面，不是通用边界检测。

## 5. rates：根据当前状态计算想要流动多少水

```python
potential = -pc - rho * (centers @ gravity)
```

`centers @ gravity` 是每个三维位置与重力向量的点积。若 z 向上、gravity=(0,0,−9.81)，则 potential=p_w+ρgz。高处在同样水压力下有更大的势，水倾向向下。

```python
F = conductance * 0.5*(kr[i]+kr[j]) * (potential[i]-potential[j])
```

F>0 表示 i→j；F<0 表示 j→i。相对渗透率这里取算术平均，使湿端能向干端推进；这是一个需用收敛实验约束的离散选择。

若有表面库存，再追加两类边：

1. 表面节点→内部节点：压力差包括 ρ|g|h、内部毛细压力与高程差，只保留吸收方向。
2. free→表面节点：指定总供水率按面面积分配。

这里算出的只是“请求通量”。表面没有水时，即使毛细吸力很大，也不能实际注入水；下一步的库存限制会阻止它。表面压力把 h 当作水平储水头的近似，不是已解析的膜形状。

## 6. exchange：为什么先聚合全部边，再交换

假设一个节点有 1 g 水，同时三条边各请求流出 0.8 g。逐边独立判断“0.8≤1”会错误地批准 2.4 g。

代码先用请求的符号确定 donor、receiver，再用 `np.bincount` 汇总每个节点的总流出、总流入。

供体比例=min(1,现有库存/请求总流出)；受体比例=min(1,剩余容量/请求总流入)。每条边取两端比例的较小值。上例供体比例为 1/2.4，所以所有相关边共同缩小。

`np.add.at(delta,donor,-transferred)` 与 `np.add.at(delta,receiver,transferred)` 使用完全相同的 transferred。add.at 能正确累计重复出现的节点编号，普通花式索引 `delta[ids] += ...` 不适合替代这种重复索引累计。

每个节点的新质量是旧质量加所有流入减所有流出。不会在末尾用 clip 丢水。代码保留 1e-14 的相对安全余量降低边界舍入风险，不会生成新水。

该方法是保守的：本步收到的水不能立即再次流出，本步流出的水也不提前释放接收容量。因此大时间步可能显著降低真实输运速度，必须有时间精度检查。

## 7. step 与 run：一个时间步和自适应积分

step 计算 rates，把 kg/s 乘 dt 得到请求交换质量，再调用 exchange。最后检查有限值和容量界限，出现显著越界就报错，而非掩盖。

run 对同一个旧状态尝试：

```text
路径 A：一次 dt
路径 B：两次 dt/2
```

比较两条路径的终态差别。孔隙节点用本节点容量归一化，因此误差可理解为饱和度变化误差。表面库存采用其关联单元容量作为误差尺度。

差别过大则拒绝该步并减小 dt；通过则接受两个半步的结果。保存每个接受步的库存和残差。此方法是显式一阶推进加步长控制，不是高阶隐式 Richards 算法。用户给定的 max_dt 仍需要减半比较，单纯守恒并不证明时间精度。

history 中的 mass_residual_kg=(free+surface+pore)−初始总质量。供水只是 free 移到 surface，不是向系统凭空增加质量。

## 8. B1 解析验证具体检查什么

run_experiments.analytic_experiment 使用封闭一维余弦分布。均匀材料、无重力、线性压力下：

```text
D = κ P0 / (μ φ)
S(x,t)=0.5+0.2 exp(−Dπ²t/L²) cos(πx/L)
```

状态代表单元平均值，因此余弦要乘 sinc(1/(2n)) 才是每格平均值。代码对 16/32/64 格比较体积加权 L2。最大 dt 随 dx² 缩小，避免固定时间误差掩盖空间收敛。

## 9. B2 与 B3 的实验作用

wetting_case 从预设有限 free 库存供水，记录 S、h 和三份库存。impermeable 将 κ=0；surface_only 只关闭内部边，仍允许表面吸收，是“仅表层吸水”消融。

bottom_gravity 与 bottom_no_gravity 对比底部供水受重力影响的趋势。half_dt 比较最大步长减半。epsilon_half 检查指定场景对干端正则化的敏感性；若 S 始终高于两个 eps，结果相同只说明正则化没有被触发，不能宣称 eps 普遍无影响。

geometry_experiments 删除中间单元形成裂缝，保留原图子边，不重新跨洞找最近邻。另用局部含水峰检查 κx>κz 时 x 方向扩散方差更大。它不验证旋转各向异性或复杂曲面离散。

## 10. H1：conservative_remap

对旧单元 i 与新单元 j 求轴对齐盒体交叠体积 Oji：

```text
新孔隙体积_j = Σ_i Oji φ_i
新水质量_j = Σ_i Oji (m_i/V_i)
新孔隙率_j = 新孔隙体积_j / 新材料体积_j
```

这相当于在旧单元中假定体积密度均匀，再按真正交叠部分转移。检查两套单元覆盖相同域，不允许遗漏、重复覆盖或跨 domain_id 转移。

与“找到最近旧节点并复制其 S、φ”比较总质量。后者在新旧分区不对齐时可能有偏差。另比较中途细化再继续输运与从开始就在细网格求解的结果：即使重映射完全守恒，两者也不必完全相同，因为粗网格已引入近似误差。

该方法是规则盒体上的精确交叠，不能据此宣称任意高斯的重采样已解决。

## 11. H2：query

先用给定连通域标签筛选节点，再计算高斯核：logw=−0.5·Mahalanobis²，体积加权时加 log(V)。减去最大 logw 再 exp，避免核非常小时全部数值下溢。

归一化权重后分别算 φ、θ=φS，然后 S=θ/φ。直接插值 S 在不同 φ 下不是同一个物理量。

查询点的材料归属必须由几何提供；函数不会仅凭高斯核猜测物体内外。测试把一个代表节点分成多个同位置、同核、体积相加不变的节点：体积加权查询应不变，而按数量加权会偏向复制较多的一侧。这是必要的一致性，不是新颖性证明。

另有真正改变节点位置与数量的 8/16/32 细化实验，分别用随单元缩小的核和固定物理宽度的核。固定核可能保留平滑偏差；报告应保留这种限制，不能只展示复制不变性。
