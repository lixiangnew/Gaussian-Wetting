# B 阶段实验方案（2026-10-09）

## 目标、边界与实施顺序

完成静止骨架下的节点质量输运、毛细/重力驱动、自由水—表面储水—孔隙水账本；初测体积守恒重采样与高斯场查询。CPU / NumPy，复用阶段 A，不修改上游 3DGS / GaussianFluent。物理参数为合成参数，不代表实测海绵或木材。

1. B1：无源封闭交换、容量约束、线性解析解、空间收敛。
2. B2：非线性毛细关系、饱和度相关迁移率、重力、有限表面水库、时间步比较、不透水对照。
3. B3：显式体素空隙/裂缝和轴对齐各向异性测试。只是规则单元掩膜，不是任意曲面裁切算法。
4. B4：候选贡献的可证伪实验：守恒重映射、高斯查询对节点密度的敏感性。记录成功和失败，不预设创新成立。

## 状态与单位

位置 m，体积 m³，质量 kg，压力 Pa，固有渗透率 m²，黏度 Pa·s，时间 s。主状态是孔隙水质量 m；S=m/(ρVφ)，零容量节点 S=0。自由液体库存 free、各表面小面的储水 surface、孔隙水 pore 分开存储。无蒸发与排水，封闭总质量应不变。

空间图来自阶段 A。只支持正交单元和轴对齐对角渗透率；拒绝把一般旋转张量直接塞进两点通量。零孔隙率或零方向渗透率节点的相应通量关闭。

## 离散与参考模型

压力 p_w=-p_c(S)，重力势 Ψ=p_w−ρ g·x。
F_ij=ρ A_ij/d_ij · harmonic(κ_i,n,κ_j,n)/μ · mean(k_r,i,k_r,j) · (Ψ_i−Ψ_j)。
正 F 表示 i→j，一次交换对两端使用同一质量。固有渗透率使用调和平均以保持零渗透率阻隔；相对渗透率采用算术平均，以避免零饱和度处的调和平均把干湿界面完全锁死。此界面选择需要收敛实验支持，不等同于已经验证的最优离散。

验证模型：p_c=P0(1−S)、k_r=1，φ、κ 常数，无重力。此时 ∂S/∂t=D∇²S，D=κP0/(μφ)。封闭一维域初值 S=0.5+0.2 cos(πx/L) 有解析解 S=0.5+0.2 exp(−Dπ²t/L²)cos(πx/L)。比较单元平均值，而非把解析中心值当单元平均值。

非线性演示：正则化 van Genuchten 压力与 Mualem 型相对渗透率（残余饱和度设为零，非材料拟合）。压力查询使用 S_eval=max(S,eps) 防止 S=0 奇异，但不裁剪或丢弃主状态水质量；饱和端 p_c=0。记录 eps 并讨论敏感性。参考实现与公式：[MOOSE capillary pressure](https://mooseframework.inl.gov/moose/modules/porous_flow/capillary_pressure.html)、[USGS SUTRA unsaturated relations](https://water.usgs.gov/nrp/gwsoftware/sour/special/unsat/unsat.htm)。

显式质量交换先聚合各节点的总流出和总流入，以供体库存和受体剩余容量共同限制每条边的交换量。不采用更新后逐点 clip。此限制保证界限但会改变大步长下的速率，因此增加全步/两个半步误差估计、自适应拒步及最大步长限制；质量守恒不是时间精度的替代。

表面水 h=M_surface/(ρA)。自由水按预设总速率分配到指定外表面，不是模拟落水接触。吸收压力差包括表面静水压力、内部毛细压力和两点重力势差；只做吸收方向，受库存和容量限制，过量水留在表面或自由水库存。表面没有横向流动、滴落或几何水膜求解。

## 实验与判据

| 实验 | 检查与输出 |
|---|---|
| 两节点与多边大步交换 | 总质量不变，每个节点有界；不能依赖后验裁剪 |
| E1 线性解析解 | 16/32/64 单元，体积加权 L2，误差应随分辨率减小；输出观测阶 |
| E2 滴水/表面水库 | 时间轨迹 free/surface/pore、h、S、账本残差；无渗透率组吸水为零 |
| E3 底部供水与重力 | 与关重力比较；短时间方向/趋势检查，不以此冒充完整参考解验证 |
| E4 时间步减半 | 同一参数、同一终止时刻，比较吸水量和体积加权状态差 |
| E5 裂缝与方向性 | 空气间隙不跨越；方向扩散方差与轴对齐渗透率变化一致 |
| H1 守恒重映射 | 利用新旧代表域交叠转移孔隙体积和水质量；对照逐点插值的质量偏差；检查继续输运后的误差 |
| H2 高斯查询 | φ(x)=Σwφ_i、θ(x)=Σwφ_iS_i、S=θ/φ；w∝V_i exp(−q_i/2)，按连通域限制支持。对照等权核、直接插值 S、跨间隙查询 |

H1 交叠积分是已知保守重映射思想；H2 体积加权、归一化和域约束本身也不是新颖性证明。若仅验证“把一个节点复制两份、各分一半体积后查询不变”，那只是代数一致性测试，必须同时报告真实细化下误差与核宽敏感性，不可包装成优于已有方法的证据。
